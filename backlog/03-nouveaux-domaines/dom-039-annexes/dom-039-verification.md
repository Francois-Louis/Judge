# DOM-039 — Vérification documentaire

Parcours relus par l'agent de maintenance le **17 octobre 2026** dans le
[découpage](dom-039-decoupage-independants.md) et les 42 suites proposées.
Il s'agit de vérifier les propriétaires, pièces et résultats annoncés sans
résoudre les consultations. Le [relevé machine](dom-039-resultats.json)
consigne les contrôles statiques reproductibles et leurs limites.

borné ; les compléments sont des questions distinctes. Les tests des futurs
skills portent sur leurs sorties, leurs sources et leur comportement réel,
pas seulement sur l'existence d'un lien ou d'un mot dans ces tableaux.

## Contrôles exécutés et reproduction

Depuis la racine :

```powershell
python -X utf8 backlog/03-nouveaux-domaines/dom-039-annexes/dom-039-controles.py --output backlog/03-nouveaux-domaines/dom-039-annexes/dom-039-resultats.json
python backlog/etat.py --check
python scripts/check-version-bump.py
git diff --check
```

Le contrôleur vérifie les identifiants/dépendances et cycles du backlog,
la cohérence table/suites, les liens locaux, les points de couverture, le
format et l'index généré, ainsi que l'absence de plugin créé ou inscrit.
Son relevé porte les résultats, la date et les empreintes des documents.
Les contrôles de paquet/schema/client ne s'appliquent pas à ce lot sans
plugin ; ils restent prévus dans les suites.

**Portée :** cadrage documentaire et parcours fictifs relus par le rédacteur,
contrôles statiques exécutés. Aucune source juridique externe ouverte : les
textes sont des pistes, les règles/chiffres des sources de besoin ne sont
pas validés. Aucun scénario métier de skill exécuté, plugin créé/installé,
paquet testé en client, démarche externe ou compréhension par un participant
observée. La relecture humaine/juridique est prise en charge par l'utilisateur,
sans être déclarée effectuée ; elle ne bloque pas la clôture du cadrage.
PILOTE-003 est terminé après BASE-011, sans sélection automatique d'une suite.
