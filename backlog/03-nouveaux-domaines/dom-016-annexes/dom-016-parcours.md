# DOM-016 — Parcours documentaires

Relecture des contrats écrits le 17 octobre 2026 par l’agent de maintenance.
Chaque scénario est détaillé dans sa suite : les pièces sont fictives, et
le résultat décrit est une attente vérifiée dans le découpage, sans sortie
d’un skill. La [vérification](dom-016-verification.md) précise la portée.
