# Dossier de classement : planches à découper en noyer, export de France vers la Suisse

## 1. En bref

**Non, en l'état, ce code ne peut pas être repris pour l'export depuis la France.** C'est un code du tarif suisse. La déclaration d'export française se fait dans la nomenclature de l'Union. Le dossier n'a encore arrêté aucun code.

- **Votre situation :** vous fabriquez des planches à découper en noyer et vous les vendez à un magasin en Suisse. L'opération est une exportation depuis la France. Je n'ai reçu aucune pièce : tout repose sur votre récit.
- **Ce que dit le droit de l'Union :**
  - Classer une marchandise, c'est trouver sa sous-position dans la nomenclature combinée de l'Union (NC), ou dans une nomenclature qui la reprend (U1 art. 57).
  - Seuls les **6 premiers chiffres** sont communs aux pays qui utilisent le Système harmonisé (SH) (N1 art. 3 ; G4).
  - Les 7e et 8e chiffres d'un code NC sont des subdivisions propres à l'Union. Un code suisse à 8 chiffres n'est donc pas une sous-position NC.
  - Je ne dis pas pour autant que ses chiffres coïncident ou diffèrent de ceux du code de l'Union. Cela se vérifie en lisant le texte.
- **Le code suisse garde une utilité :** il sert au classement à l'arrivée en Suisse, qui est l'affaire de l'acheteur ou de son transitaire.
- **Alerte :** je n'ai connaissance d'aucun acte de la douane ni d'aucune demande de « code plus avantageux ». La demande de l'acheteur n'est pas suspecte. Mais reporter un code étranger comme s'il était le code de l'Union rendrait la donnée inexacte. Or la personne qui fournit les données d'une déclaration répond de leur exactitude (U1 art. 15 § 2).
- **Mesures et conformité :** je n'affirme pas que le produit échappe à toute mesure. Deux questions restent à vérifier par votre représentant ou le service compétent :
  - les mesures liées au bois ou à l'export ;
  - les exigences suisses pour un objet en contact avec les aliments.
- **Prochaine étape :** documenter les attributs du produit (section 3). Votre représentant en douane, ou vous-même si vous déclarez, retiendra ensuite le code NC de la déclaration.

## 3. Attributs manquants, du plus décisif au moins décisif

1. **Composition complète.** Bois seul ou associé à d'autres matières, avec leurs proportions (RGI 2 b et 3). Le texte du tarif peut distinguer selon la matière. Pièce : votre fiche de fabrication.
2. **Présentation.** Planche seule ou ensemble avec un autre article (RGI 3 b, RGI 5). Si un couteau est joint, c'est aussi un produit sensible : le classement ne dit rien de son admissibilité.
3. **Fonction principale.** Découpe, service ou décoration. C'est ce qui permet de comparer les termes des positions (RGI 1).
4. **Mode de fabrication et finition.** Massif, assemblé, traitement de surface.
5. **Dimensions et caractéristiques chiffrées.** Elles peuvent départager des sous-positions voisines (RGI 6).
6. **Date de l'export.** Il faut appliquer la NC de l'année des faits. Pour 2026, c'est l'annexe I consolidée au 1er janvier 2026. La version 2027 n'avait pas été trouvée lors de la recherche du 20 octobre 2026.

Je ne cite ici aucune position ni aucun chapitre du tarif, faute d'avoir lu les passages concernés. Les positions concurrentes restent à identifier en lisant le texte de la NC à partir de ces attributs.

Questions qui restent ouvertes :
- Quel code NC le déclarant retiendra-t-il, sur quels textes de position et quelles notes ?
- Faut-il faire figurer sur la facture les deux codes, chacun avec son pays (« code NC » / « code tarifaire suisse communiqué par l'acheteur ») ? Si oui, sous quelle mention ?
- La facture rédigée en anglais pose-t-elle une question au départ ou à l'arrivée ?

Je n'énonce aucune règle sur ces points. Ce sont des questions pour votre représentant et pour l'acheteur. Si le code suisse figure sur un document, l'indiquer comme code suisse permet d'éviter toute confusion avec le code de l'Union.

## 5. Décision fournie

Aucune. Même si vous obteniez un jour un RTC (renseignement tarifaire contraignant) en France, il ne serait pas directement opposable à la douane suisse (G1). Le classement à destination reste l'affaire de l'acheteur.

## 6. Voie officielle de renseignement

- **Représentant en douane, ou transitaire qui déclare l'export :** c'est lui qui retient le code de la déclaration qu'il dépose.
- **Service d'information de la douane :** il répond aux questions générales sur les positions à examiner. Sa réponse n'est pas une décision.
- **RTC :** c'est une décision contraignante pour son titulaire, sur demande, pour une utilisation prévue (U1 art. 33). La demande se fait en ligne dans le service EBTI, avec un compte certifié et l'EORI au format SIREN. Elle est gratuite et rédigée en français (G1, G5, guides à revérifier). Il peut être utile si vous exportez souvent.
  - Pièces d'une future demande : description détaillée, composition, photos, brochure, éventuels échantillons, code attendu, décisions connues pour des produits identiques ou similaires.
  - Rien n'est rempli ni déposé ici.
- **Questions séparées :**
  - L'**origine** (« fabriqué en France » est votre déclaration) ne se déduit pas du code. C'est la tâche DOU-007, proposée mais non disponible.
  - La **valeur** est elle aussi une question à part (DOU-008, proposée).
  - Les **formalités de l'export** (pièces, déclarant, sortie) relèvent de la commande `export-document-preparation`.
