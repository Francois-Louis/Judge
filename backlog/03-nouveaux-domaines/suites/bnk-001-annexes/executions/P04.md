## 2. Branche : ouverte

Vous avez fait un geste, le code saisi. L'**authentification**, c'est-à-dire la vérification technique que le bon code a été entré, a donc pu avoir lieu. Mais cette vérification ne montre pas à elle seule que vous étiez d'accord pour **ce** paiement de 700 EUR à **ce** bénéficiaire : c'est la question du **consentement**, votre accord au paiement. La « négligence grave » est une affirmation de la banque. Elle n'est ni prouvée ni à admettre à ce stade, et je ne conclus ni dans un sens ni dans l'autre.

Deux questions permettent d'avancer. Répondez sans jamais donner le code :
1. **Que disait le message ou l'écran au moment où vous avez saisi le code ?** Y avait-il un montant, un nom de bénéficiaire, un mot comme « paiement », « virement », « ajout de bénéficiaire » ou « annulation » ?
2. **Ce débit vient-il d'une carte ou d'un virement ?** Le libellé du relevé suffit à le savoir.

Le traitement approfondi d'une validation obtenue par tromperie est une étape prévue mais **pas disponible dans cet outil**. La réponse ci-dessous se limite donc à demander les preuves et un réexamen.
